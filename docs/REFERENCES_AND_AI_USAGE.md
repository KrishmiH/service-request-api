# References, Packages and AI Usage

- Laravel 12 – Backend framework.
- Laravel Sanctum – API token authentication.
- PHPUnit – Automated testing.
- Laravel Pint – PHP code formatting.
- SQLite – Development database.
- Postman – API testing and documentation.
- Composer – PHP dependency management.

## AI Usage

ChatGPT was used as a development assistance tool during this assignment. It helped with understanding Laravel concepts, discussing implementation approaches, troubleshooting errors, preparing API documentation, and reviewing parts of the implementation.

All suggested changes were reviewed and tested in the project. I used the implementation and testing process to understand the code and the design decisions.
